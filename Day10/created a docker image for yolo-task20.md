# Traffic Violation Detection using YOLO

## Docker Image

Docker Hub:

ajayajay12/traffic-violation:latest

Pull Image:

docker pull ajayajay12/traffic-violation:latest

Run Container:

docker run --rm -it ajayajay12/traffic-violation:latest

## Project

This project uses a custom-trained YOLO model to detect traffic-related objects from video input.

## Technologies

* Python
* YOLO (Ultralytics)
* OpenCV
* Docker
